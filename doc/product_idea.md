# Идея продукта: ИИ-ассистент для первичной консультации клиентов

## Описание

Разработка ИИ-ассистента в виде Telegram бота для проведения первичной консультации клиентов по оказываемым услугам.

## Основной функционал

### 1. Информационная функция
- Рассказ о специалисте (опыт, квалификация)
- Демонстрация портфолио
- Описание оказываемых услуг

### 2. Консультационная функция
- Обработка вопросов потенциальных клиентов
- Уточнение потребностей и проблем клиентов
- Предложение услуг для решения задач клиентов

## Технические особенности

- **Платформа**: Telegram бот
- **Технология**: ИИ-ассистент (LLM-based)
- **Конфигурация**: Информация о специалисте и услугах добавляется вручную в системный промт
- **История диалога**: будет храниться в памяти, база данных не предусмотрена

## Цель

Автоматизация первичного этапа взаимодействия с потенциальными клиентами, предоставление базовой информации и проведение первичной консультации для выявления потребностей клиентов.
