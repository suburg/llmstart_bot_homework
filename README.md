## О проекте

ИИ-ассистент в виде Telegram бота для совместного сочинения детских историй. Бот помогает детям 8-12 лет создавать увлекательные истории, развивая креативность, воображение и грамотность.

### Основные возможности

- 📖 **Интерактивное сочинение** - пользователь и бот по очереди пишут историю
- 🎭 **Выбор жанров** - сказка, приключение, фантастика, детектив и другие
- 🎨 **Уровни креативности** - от спокойного до очень креативного повествования
- 🎤 **Голосовой ввод** - можно сочинять историю голосом
- 🖼️ **Загрузка изображений** - задать тему истории через картинку
- 🎁 **Генерация обложек** - красивые обложки для каждой истории
- 💾 **Сохранение историй** - все истории сохраняются в базе данных
- 🌟 **Персональная похвала** - бот хвалит ребенка за креативность

## 🚀 Быстрый старт

> **Примечание:** Makefile полностью кроссплатформенный и работает как на Windows (PowerShell), так и на Linux/macOS (bash).

### Вариант 1: Запуск локально

```bash
# 1. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env - добавить токены API

# 2. Установить зависимости
make install

# 3. Инициализировать базу данных
make init-db

# 4. Создать справочник жанров
# Создать data/genres.json (пример в документации)

# 5. Запустить бота
make run              # Запуск в текущем терминале (для разработки)
# ИЛИ
make start            # Запуск в фоновом режиме

# 6. Управление ботом в фоновом режиме
make status           # Проверить статус бота
make stop             # Остановить бота
```

### Вариант 2: Запуск в Docker

```bash
# 1. Настроить .env (см. выше)

# 2. Собрать образ
make docker-build

# 3. Запустить контейнер
# Production (detached mode, auto-restart):
make docker-deploy

# ИЛИ для разработки (foreground mode):
make docker-run

# 4. Просмотр логов
make docker-logs

# 5. Остановка
make docker-stop
```

**Примечание:** 
- `make docker-deploy` автоматически создаёт директории `data/images/uploads` и `data/images/covers`
- Volume `data/` монтируется для сохранения БД и изображений между перезапусками
- `data/genres.json` копируется в образ при сборке

## 📋 Команды бота

- `/start` - начало работы, приветствие
- `/help` - помощь и описание возможностей
- `/new_story` - создать новую историю
- `/my_stories` - просмотреть сохраненные истории

## 🎯 Как это работает

1. **Создание истории**: пользователь выбирает жанр, длительность, героев, уровень креативности
2. **Сочинение**: бот и пользователь по очереди добавляют по 2-3 предложения
3. **Завершение**: бот предлагает завершить когда достигнута заданная длительность
4. **Финализация**: бот создает название, генерирует обложку и хвалит ребенка
5. **Сохранение**: история сохраняется в базу данных для повторного просмотра

## 🔧 Требования

- Python 3.11+ (для локального запуска)
- Docker (для контейнеризации)
- API ключи:
  - Telegram Bot Token
  - LLM API (polza.ai или OpenAI)
  - Speech-to-Text API (опционально)
  - Image Generation API (опционально)
  - Vision API (опционально)

## 🛠️ Доступные команды Makefile

### Управление зависимостями и базой данных
- `make install` - установка зависимостей через uv
- `make init-db` - инициализация базы данных

### Запуск бота (локально)
- `make run` - запуск бота в текущем терминале (для разработки)
- `make start` - запуск бота в фоновом режиме
- `make stop` - остановка бота, запущенного в фоновом режиме
- `make status` - проверка статуса бота

### Docker команды
- `make docker-build` - сборка Docker образа
- `make docker-deploy` - запуск контейнера в production режиме (detached, auto-restart)
- `make docker-run` - запуск контейнера в foreground режиме (для разработки)
- `make docker-stop` - остановка и удаление контейнера
- `make docker-logs` - просмотр логов контейнера

### Утилиты
- `make test` - запуск тестов
- `make clean` - очистка временных файлов и кеша

> **Совместимость:** Все команды работают одинаково на Windows (PowerShell), Linux и macOS (bash).
