## О проекте

ИИ-ассистент в виде Telegram бота для совместного сочинения детских историй. Бот помогает детям 8-12 лет создавать увлекательные истории, развивая креативность, воображение и грамотность.

### Основные возможности

- 📖 **Интерактивное сочинение** - пользователь и бот по очереди пишут историю
- 🎭 **Выбор жанров** - сказка, приключение, фантастика, детектив и другие
- 🎨 **Уровни креативности** - от спокойного до очень креативного повествования
- 🎤 **Голосовой ввод** - можно сочинять историю голосом
- 🖼️ **Загрузка изображений** - задать тему истории через картинку
- 🎁 **Генерация обложек** - красивые обложки для каждой истории
- 💾 **Сохранение историй** - все истории сохраняются в базе данных
- 🌟 **Персональная похвала** - бот хвалит ребенка за креативность

## 📋 Команды бота

- `/start` - начало работы, приветствие
- `/help` - помощь и описание возможностей
- `/new_story` - создать новую историю
- `/my_stories` - просмотреть сохраненные истории

## 🎯 Как это работает

1. **Создание истории**: пользователь выбирает жанр, длительность, героев, уровень креативности
2. **Сочинение**: бот и пользователь по очереди добавляют по 2-3 предложения
3. **Завершение**: бот предлагает завершить когда достигнута заданная длительность
4. **Финализация**: бот создает название, генерирует обложку и хвалит ребенка
5. **Сохранение**: история сохраняется в базу данных для повторного просмотра

## 🔧 Требования

- Python 3.11+ (для локального запуска)
- Docker (для контейнеризации)
- API ключи:
  - Telegram Bot Token
  - LLM API (polza.ai или OpenAI)
  - Speech-to-Text API (опционально)
  - Image Generation API (опционально)
  - Vision API (опционально)
