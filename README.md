## О проекте

ИИ-ассистент в виде Telegram бота для первичной консультации клиентов. Бот использует LLM (через OpenRouter) для ведения диалогов и консультирования.

## 🚀 Быстрый старт

### Вариант 1: Запуск локально

```bash
# 1. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env - добавить токены

# 2. Установить зависимости
make install

# 3. Запустить бота
make run
```

### Вариант 2: Запуск в Docker

```bash
# 1. Настроить .env (см. выше)

# 2. Собрать образ
make docker-build

# 3. Запустить контейнер
make docker-deploy

# 4. Просмотр логов
make docker-logs

# 5. Остановка
make docker-stop
```

## 📋 Команды бота

- `/start` - начало работы, приветствие
- `/help` - помощь и описание возможностей
- `/clear` - очистить историю диалога

## 🧪 Тестирование

```bash
# Установить dev-зависимости
uv sync --all-extras

# Запустить тесты
make test
```
